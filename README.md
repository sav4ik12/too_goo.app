# TooGoo — сайт

Одностраничный сайт курьерского приложения TooGoo. Один файл `index.html`, без сборки и зависимостей.

## Как выложить на GitHub Pages

1. Создайте на GitHub **публичный** репозиторий (например, `toogoo`).
2. Нажмите **Add file → Upload files**, перетащите `index.html` и `README.md`, нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В блоке *Build and deployment* выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**, нажмите **Save**.
4. Через минуту сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/toogoo/`.

## Как подключить скачивание APK

Файл приложения весит больше 25 МБ, поэтому в сам репозиторий его не кладите. Выложите его в релиз:

1. В репозитории откройте **Releases → Create a new release**.
2. В поле *tag* введите, например, `v1.0`.
3. Перетащите `app-release.apk` в область файлов и **переименуйте его в `toogoo.apk`** (имя важно).
4. Нажмите **Publish release**.

Кнопка «Скачать APK» на сайте сама ведёт на `releases/latest/download/toogoo.apk` вашего репозитория. Ссылку вручную менять не нужно. Чтобы выпустить новую версию, создайте новый релиз с файлом `toogoo.apk`.

Если сайт открыт на собственном домене, а не на `github.io`, в `index.html` найдите `id="apk"` и впишите в `href` прямую ссылку на APK.
